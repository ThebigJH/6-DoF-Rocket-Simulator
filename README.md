# 6-DoF-Rocket-Simulator

A 6 degrees of freedom rocket flight simulator that models complete translational and rotational physics. It tracks full spatial movement across all three linear axes (surge, sway, heave) and rotational axes (pitch, roll, yaw). Designed for trajectory analysis and control system testing, it accounts for variable mass, changing aerodynamics, atmospheric wind, and thrust vectoring to deliver accurate flight telemetry.
